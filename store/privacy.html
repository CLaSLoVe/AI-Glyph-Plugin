AI Glyph 隐私政策

Privacy Policy · 生效日期 Effective date: 21 October 2026

AI Glyph 是一个浏览器扩展。它把网页上看得见的文字画成合成字形：看起来像字母或汉字，但并不是真实存在的字。This extension redraws visible page text as synthetic glyphs. Those shapes are not real characters.

它处理哪些数据 / What it handles

  • 页面文字 / Website content。扩展会在你的设备上读取网页里看得见的文字，用来画出合成字形。这些文字只留在当前页面里，不会被保存，不会被记录，也不会发送给开发者或任何服务器。The extension reads visible text on your device in order to draw the glyphs. That text is not stored, logged, or sent to the developer or to any server.
  • 它不读取输入框、密码框、文本框和可编辑区域。It does not read input fields, password fields, text areas, or editable regions.
  • 它不读取 Cookie、密码、账号、支付信息、浏览历史，也不记录你访问了哪些网站。It does not read cookies, passwords, account data, payment data, or browsing history, and it does not record which sites you visit.

它保存哪些设置 / Settings it stores

扩展只用 chrome.storage.sync 保存两项设置：效果是否开启，以及强度（5 到 100 的数字）。除此之外不保存任何内容。如果你开启了 Chrome 同步，这两项设置会同步到你自己的 Google 账号。开发者收不到这些数据。The extension stores only whether the effect is on and the intensity, a number from 5 to 100. If Chrome Sync is on, those two preferences sync to your own Google account. The developer does not receive them.

网络 / Network

扩展不会发起网络请求，也不加载远程代码。The extension makes no network requests and does not load remote code.

共享 / Sharing

开发者不出售、不转让、不向第三方提供上述数据。页面文字不会离开你的浏览器。The developer does not sell or transfer this data. Page text does not leave your browser.

联系 / Contact

请使用 Chrome 网上应用店商品页上公布的支持邮箱联系开发者。Contact the developer at the support email published on the Chrome Web Store listing.
